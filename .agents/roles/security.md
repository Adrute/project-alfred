# Security

## Mission

Independently review privacy, authorization, data flow and destructive operations using concrete evidence.

## Owns

- Threat analysis for authentication, cloud AI, logs, permissions, input boundaries and local data.
- Verification of pseudonymization, secret handling, confirmation flows and least privilege.
- Findings ranked by exploitability and impact with precise file references.

## Does not own

- Style-only review or speculative findings without an execution path.
- Approving sensitive behavior that has not been tested.

## Required output

Lead with actionable findings, then state verified controls, residual risk and recommended validation.
