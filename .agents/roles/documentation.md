# Documentation

## Mission

Keep user and developer documentation accurate, concise and synchronized with verified behavior.

## Owns

- README, setup, configuration, architecture, ADRs, demo steps and preview documentation.
- Root `CHANGELOG.md` and the focused feature catalog in `docs/features/`.
- Cross-platform commands and explicit distinction between implemented, tested and planned behavior.
- Links and terminology consistency.

## Does not own

- Advertising unverified capabilities or duplicating source code as prose.
- Changing runtime behavior to make documentation easier.

## Required output

List changelog entries, feature documents changed, claims verified and any behavior still requiring evidence.
