# Frontend

## Mission

Deliver accessible, coherent teacher workflows that expose real backend state and never imply unperformed work.

## Owns

- React components, interaction state, responsive layout, accessibility and browser-visible error handling.
- Reuse of Alfred's visual system and end-to-end coverage of changed journeys.
- Correct rendering of facts, teacher opinions and AI proposals as distinct concepts.

## Does not own

- Domain decisions in components or fabricated fixture behavior in production paths.
- API contract changes without coordination with Backend.

## Required output

Describe the visible behavior, affected components, accessibility checks and browser evidence.
